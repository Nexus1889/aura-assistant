# Настройка AURA в приложении

Все основные параметры находятся в разделе **Настройки** (иконка шестерёнки в боковой навигации). Вверху панели есть поиск по названиям пунктов. После изменений нажмите **Сохранить**.

*Актуальная версия приложения: 0.4.4.*

## 🚀 С чего начать
Рекомендуемый порядок после установки:
1. **Голос и микрофон** — устройство ввода, чувствительность, язык распознавания.
2. **Пробуждение** — Wake word и фоновый режим.
3. **Озвучка** — голос и громкость ответов.
4. **Интерфейс** — язык и внешний вид.
5. По желанию: Модель ИИ, Характер ИИ, Визуализация, Подтверждения.

*Проверка:* на дашборде нажмите микрофон и скажите короткую фразу.

## ⚙️ Разделы настроек

### 🎨 Интерфейс
| Параметр | Зачем |
| --- | --- |
| Язык интерфейса | Русский / English — язык UI и ответов ассистента |
| Оптимизация | Снижает нагрузку на систему. После смены перезапустите AURA |
| Акцентный цвет | Цвета подсветок и панелей интерфейса |
| Анимации | Плавные переходы; можно выключить на слабом ПК |
| Лёгкий UI | Уменьшает эффект размытия (glass-blur) для повышения производительности |
| Стиль стекла | Лёгкий / сбалансированный / полный; слайдеры прозрачности и «глубины» |

### ✅ Подтверждения
Как AURA спрашивает «выполнить?» перед командой и доступом к экрану:
- **Визуально (окно)** — всплывающее окно.
- **Голосом** — скажите «да» / «нет».
- **Автоматически** — обычные подтверждения пропускаются.

> 🛡️ **Важно:** Критичные команды (выключение, перезагрузка, сон, выход из Windows) **всегда** требуют явного подтверждения, даже в автоматическом режиме.

### 🎙️ Голос и микрофон
| Параметр | Зачем |
| --- | --- |
| Модель распознавания | Быстрый и точный серверный Whisper |
| Качество распознавания | Пресет микрофона + STT для максимальной точности |
| Язык распознавания | Авто / русский / English |
| Микрофон | Устройство ввода (или системное по умолчанию) |
| Чувствительность микрофона | Выше — если говорите тихо; слишком высоко — больше шума |
| Порог VAD | Выше — строже к фоновому шуму, позже старт фразы |

*Без рабочего микрофона в Windows голосовые команды не заработают: Параметры Windows → Конфиденциальность → Микрофон.*

### 🔔 Пробуждение
| Параметр | Зачем |
| --- | --- |
| Wake word | Вкл: команды начинаются с фразы активации (кроме подтверждений). Выкл: можно говорить и без «Аура» |
| Фоновый режим | Вкл: AURA слушает в фоне. Выкл: работает только кнопка микрофона на дашборде |
| Фразы активации | До 25 тегов. По умолчанию `AURA` и `Аура`. Enter или пробел — добавить |

*Типичная схема:* включите Wake word и Фоновый режим, затем говорите:  
*«Аура, открой браузер»*  
*«Аура, сделай громче»*  
После одной только фразы «Аура» у вас есть короткое окно (~30 с), чтобы произнести саму команду.

### 🗣️ Озвучка
| Параметр | Зачем |
| --- | --- |
| Движок | Качественный синтез речи (Silero и продвинутые модели) |
| Голос | Ксения, Евгений, Аура, Мита, Джарвис, Диппер, Рик Санчес и др. |
| Тихий режим | Только текст, без голосовой речи |
| Громкость озвучки | Уровень громкости TTS |
| Тест | Прослушать выбранный голос |

### 🧠 Характер ИИ
Стиль речи и тон ответов в голосовых командах и чате. Выберите готовый образ или задайте свой. Голос TTS настраивается отдельно в разделе Озвучка.

### 🤖 Модель ИИ
| Параметр | Зачем |
| --- | --- |
| AI-провайдер | Встроенный или свой ключ: OpenAI, Mistral, DeepSeek, OpenRouter, Anthropic, Google |
| Модель | Список зависит от выбранного провайдера |
| Температура | 0 — точнее, 1 — свободнее и креативнее |
| API-ключи | Хранятся локально на вашем ПК |

### 👁️ Визуализация
Поверх окон можно показать:
- **Выключено**
- **Островок (AuraBubble)** — компактный статус: слушаю / отвечаю / выполняю и т.д.
- **3D-аватар** — VRM-модель с эмоциями и анимациями; можно загрузить свою `.vrm` до 64 МБ

*Островок и аватар взаимоисключающие: включение одного выключает другой.*  
*В exclusive fullscreen (многие игры DirectX) оверлеи скрываются, чтобы Windows не сворачивала игру. Команды и голос продолжают работать.*

### 📁 Работа с файлами
Список дисков и папок, где AURA может искать, открывать и читать файлы (Документы, Рабочий стол, Загрузки, папки AURA Documents / Presentations / Spreadsheets и ваши пути). Добавляйте только нужные каталоги для безопасности.

### 🕵️ Режим агента (Agent)
Многошаговые автономные задачи с отдельными разрешениями (мышь, клавиатура, окна, файлы, сеть). Обычные голосовые команды работают и без агента.

### 👀 Vision режим
- **Чтение экрана** — анализ дерева UI и снимков для описания содержимого.
- **Управление экраном** — клики, ввод, жесты.  
*Перед действиями AURA запрашивает согласие (см. также раздел Подтверждения).*

### 💻 Система
Уведомления Windows и автозапуск при входе в систему.

### ℹ️ О приложении
Версия AURA, открытие папки с логами, сведения для поддержки.

## 🎯 Как пользоваться после настройки

**Кнопка микрофона (дашборд)**
1. Нажмите микрофон — начался живой диалог.
2. Говорите.
3. Нажмите ещё раз — завершить. При авто-тишине запись может остановиться сама.  
*(Кнопку не нужно удерживать).*

**Wake + фон**  
При включённых Wake word и Фоновом режиме вызывайте AURA фразой активации из любой программы (пока микрофон разрешён системе).

**Текстовый чат**  
На дашборде можно писать запросы текстом — удобно, если микрофон занят или нужно вставить длинный текст.

## 💎 Все функции доступны бесплатно
В AURA нет разделения на тарифы. Все возможности, включая:
- Неограниченные системные команды
- Визуальный конструктор графов
- 3D VRM-аватары
- Режимы Agent и Vision
работают **полностью бесплатно** и без искусственных лимитов.
