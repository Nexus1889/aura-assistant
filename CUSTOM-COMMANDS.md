# Свои (кастомные) команды AURA

В AURA есть два типа команд:
| Тип | Где | Что это |
| --- | --- | --- |
| Системные | Команды → Системные | 281 готовое действие AURA (открыть приложение, громкость, окна…) — [COMMANDS.md](./COMMANDS.md) |
| Свои | Команды → Свои | Ваши уникальные сценарии на визуальном холсте: фраза → шаги → ответ |

Этот гайд посвящён созданию своих команд.

## 💡 Зачем они нужны
Соберите цепочку действий под одну фразу, например:
- *«Аура, рабочий режим»* → свернуть всё → открыть браузер → открыть Telegram → сказать «Готово».
- *«Аура, фокус»* → выключить звук → включить «Не беспокоить» → показать уведомление.

Так вы не повторяете длинные инструкции каждый раз, а автоматизируете рутину.

---

## 🚀 Быстрый старт

1. Откройте раздел **Команды** в боковой навигации приложения.
2. Перейдите на вкладку **Свои** (или создайте новую команду кнопкой «Новая» / «+»).
3. Задайте название и фразы-триггеры (то, что нужно сказать голосом).
4. На холсте соберите узлы: `Триггер` → `Действие(я)` → `Ответ` (и при необходимости `Условия` / `Подтверждение`).
5. Сохраните команду и убедитесь, что она включена.
6. Проверьте работу:
   - Кнопкой **Запустить** в панели команды, или
   - Голосом (с wake-фразой, если включено фоновое прослушивание).

## 🧩 Узлы на холсте

Типичный сценарий выглядит так:
```text
[Триггер] → [Действие] → [Действие] → [Ответ]
                ↓
           [Подтверждение]   (для опасных шагов)
                ↓
           [Условие] → ветка «да» / «нет»
```

| Узел | Назначение |
| --- | --- |
| **Триггер** | Фразы активации сценария (можно добавить несколько вариантов) |
| **Действие** | Конкретный шаг: открыть приложение, изменить громкость, нажать горячую клавишу, выполнить системную команду AURA и т.д. |
| **Ответ** | Что сказать или показать пользователю; можно настроить несколько вариантов ответов |
| **Подтверждение** | Спросить «выполнить?» голосом или через окно перед опасным шагом |
| **Условие** | Ветвление по состоянию (например, проверка перед следующим шагом) |
| **Конец** | Завершение ветки сценария |

> 💡 **Совет:** Соединяйте узлы, перетаскивая линию от выходного порта к входному. Неверные связи блокируются редактором.

## ⚙️ Какие действия можно ставить

В редакторе доступны группы действий, в том числе:
- **Система**: системная команда AURA по фразе, скриншот, корзина, диспетчер задач, блокировка экрана…
- **Приложения**: открыть / закрыть / сфокусировать окно.
- **Окна**: свернуть, развернуть, прикрепить (snap) влево/вправо/по углам, переключить рабочий стол…
- **Браузер**: открыть URL, выполнить поиск, управлять вкладками (назад/вперёд/обновить).
- **Звук**: громче/тише, mute, установить громкость %, управлять микрофоном.
- **Клавиатура / мышь**: нажать клавишу, сочетание, последовательность клавиш, ввод текста, управление мышью.
- **Таймеры**: установить таймер или напоминание.
- **Папки**: открыть Загрузки, Документы, рабочий стол, корзину.
- **Буфер обмена**: прочитать или записать текст.
- **Прочее**: пауза (задержка), уведомление Windows, выполнение PowerShell-скрипта (выключено по умолчанию — включайте осознанно).

> 🛡️ **Важно:** Перед опасными шагами (удаление файлов, выключение ПК) всегда добавляйте узел **Подтверждение**.

## 🖱️ Управление холстом

Те же приёмы, что и в стандартных визуальных редакторах:
| Действие | Как выполнить |
| --- | --- |
| Добавить узел | ПКМ (правая кнопка мыши) по пустому холсту |
| Меню узла | ПКМ по узлу → копировать / дудировать / удалить |
| Удалить связь | ПКМ по линии связи |
| Соединить узлы | Тянуть линию от выходного порта к входному |
| Двигать холст | Средняя кнопка мыши (колёсико) + перетаскивание |
| Масштаб | `Ctrl` + колёсико мыши |
| Выделить несколько | ЛКМ-рамка; `Shift` + ЛКМ — добавить к выделению |
| Переместить узел | ЛКМ-перетаскивание |
| Настройки узла | Двойной клик по узлу |
| Удалить выделенное | `Delete` или `Backspace` |
| Копировать / вставить / дублировать | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Shift+Z` |

## 📝 Пример: «Собери рабочий стол»

1. Создайте команду, задайте триггеры: `рабочий режим`, `собери стол`.
2. Добавьте действия по порядку:
   - Свернуть все окна.
   - Открыть браузер (или конкретный URL).
   - Открыть Telegram.
3. В конце добавьте узел **Ответ**: «Рабочий режим готов».
4. Сохраните и включите команду.
5. Скажите: *«Аура, рабочий режим»*.

## 📤 Импорт и экспорт

В разделе **Команды** можно экспортировать свои сценарии (чтобы сохранить резервную копию или перенести на другой ПК) и импортировать ранее сохранённый файл. После импорта обязательно проверьте фразы-триггеры и убедитесь, что команда включена.

## 🔧 Советы и решение проблем

| Проблема | Что проверить |
| --- | --- |
| Не реагирует на фразу | Команда включена; включены Wake word и фоновый режим; нет конфликта с другой фразой |
| Сценарий обрывается на шаге | Логи в *Настройки → О приложении*; не блокирует ли узел подтверждения |
| Открывается не то приложение | Укажите точное имя в действии «Открыть приложение» |
| Нет доступа к файлам | *Настройки → Работа с файлами* — добавьте нужные папки в разрешённые |

**Дополнительные советы:**
- Используйте короткие и уникальные фразы-триггеры, чтобы избежать путаницы с системными командами и ИИ-диалогом.
- Один сценарий — одна задача. Сложные процессы лучше разбить на несколько отдельных команд.
- Системные команды из каталога можно вызывать и из своих сценариев (используя действие «Системная команда AURA»).
