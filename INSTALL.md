# Установка AURA Assistant

**Скачать:** [Релизы на GitHub](https://github.com/Nexus1889/aura-assistant/releases)  
**Актуальный релиз:** 0.4.4. Один установщик x64 для Windows 10 и Windows 11. Размер файла — около 287 МБ.

> ⚠️ **Важно:** Установщик не имеет цифровой подписи издателя. Windows и браузер могут показать предупреждения — это абсолютно нормально для независимых open-source проектов. Ниже приведена инструкция, как безопасно установить приложение.

## 💻 Системные требования
| Компонент | Требование |
| --- | --- |
| **ОС** | Windows 10 (версия 1903 и новее) 64-бит или Windows 11 |
| **Место на диске** | Установщик ~287 МБ + запас под кэш и пользовательские данные |
| **Интернет** | Требуется для входа, распознавания речи, озвучки и ИИ-диалогов |
| **Микрофон** | Необходим для голосовых команд и фонового прослушивания |

## 📥 Скачивание
Скачивайте установщик **только** из официального раздела [Releases](https://github.com/Nexus1889/aura-assistant/releases) этого репозитория:
| Файл | Назначение |
| --- | --- |
| `AURA-Assistant-Setup-x64.exe` | Актуальный установщик (прямая ссылка на скачивание) |

## 🛡️ Почему Windows предупреждает о файле?
AURA распространяется бесплатно и без платной цифровой подписи (code signing). Поэтому:
- Браузер может написать, что файл «может быть опасен».
- SmartScreen Windows показывает сообщение: «Система Windows защитила ваш компьютер».
- Иногда срабатывает Защитник Windows с пометкой о неизвестном издателе.

**Это не означает, что файл повреждён или содержит вирусы.** Так бывает у многих независимых приложений. Главное правило безопасности: скачивать установщик только из официального раздела Releases этого репозитория.

## ⚙️ Установка по шагам

**1. Сохраните файл и проверьте источник**  
Убедитесь, что вы скачиваете файл с `github.com/Nexus1889/aura-assistant`. Не открывайте установщики из писем или чатов от неизвестных лиц.

**2. Если браузер блокирует скачивание**  
В Chrome / Edge: в списке загрузок нажмите `⋯` → **Оставить** (Keep). При необходимости подтвердите «Всё равно скачать».

**3. Обход SmartScreen при запуске**  
Дважды кликните по файлу `AURA-Assistant-Setup-x64.exe`.  
Если появится синее окно SmartScreen:
1. Нажмите ссылку **Подробнее** (More info).
2. Затем нажмите кнопку **Всё равно запустить** (Run anyway).  
*(Если Windows запросит разрешение администратора — подтвердите запуск).*

**4. Мастер установки**  
Выберите папку для установки (или оставьте предложенную по умолчанию). При желании включите создание ярлыка на рабочем столе. Нажмите **Установить** и дождитесь завершения.

**5. Первый запуск**  
- Разрешите AURA доступ к микрофону, если Windows задаст такой вопрос.
- Пройдите короткий мастер настройки: проверка микрофона и записи голоса.
- Войдите в приложение (через доступные методы авторизации).
- При необходимости выберите язык интерфейса.

**6. Проверка голоса**  
На главном экране (дашборде) нажмите кнопку микрофона и скажите коротко: *«Привет»*.  
Нажмите кнопку ещё раз, чтобы завершить разговор. Если включено автоопределение тишины, запись может остановиться сама.

Далее рекомендуем настроить микрофон, фразы пробуждения и озвучку: [SETTINGS.md](./SETTINGS.md).

## 🔧 Если Защитник Windows удаляет или блокирует файл
1. Откройте **Безопасность Windows** → **Защита от вирусов и угроз** → **Журнал защиты**.
2. Найдите действие по файлу AURA и выберите **Восстановить** или **Разрешить**.
3. Повторно скачайте установщик из раздела Releases и добавьте папку загрузок в исключения, *только если вы полностью уверены в источнике файла*.
> 🛑 **Не отключайте антивирус целиком** «на всякий случай».

## 🎤 Настройка микрофона в Windows
1. **Параметры** → **Конфиденциальность и защита** → **Микрофон** — разрешите доступ приложениям (включая классические desktop-приложения).
2. **Параметры** → **Система** → **Звук** → **Ввод** — выберите нужное устройство микрофона.
3. В AURA: **Настройки** → **Голос и микрофон**.

## 🔄 Обновление
AURA проверяет наличие обновлений при запуске. При выходе новой версии появится уведомление «Доступно обновление».  
Вы можете скачать и установить его прямо из приложения. Либо вручную скачайте новый `AURA-Assistant-Setup-x64.exe` из раздела Releases и установите поверх старой версии.

## 🗑️ Удаление
**Параметры** → **Приложения** → **Установленные приложения** → **AURA Assistant** → **Удалить**.  
*Пользовательские данные:* `%APPDATA%\aura-assistant-desktop\`  
Удалите эту папку вручную через Проводник, только если требуется полная очистка (настройки, локальные ключи, история).
