# Установка AURA Assistant

**Скачать:** [aura-assistant.ru/download](https://aura-assistant.ru/download)  
**Актуальный релиз:** 0.4.4. Один NSIS-установщик x64 для Windows 10 и Windows 11. Размер файла — около 287 МБ.

> ⚠️ **Важно:** Установщик не подписан цифровой подписью издателя. Windows и браузер могут показать предупреждения — это ожидаемо для независимых проектов. Ниже — инструкция, как безопасно установить приложение.

## 💻 Системные требования
| Компонент | Требование |
| --- | --- |
| **ОС** | Windows 10 (1903+) 64-бит или Windows 11 |
| **Место на диске** | Установщик ~287 МБ + запас под кэш и данные |
| **Интернет** | Нужен для входа, распознавания речи, озвучки и ответов ИИ |
| **Микрофон** | Нужен для голосовых команд и фонового прослушивания |

## 📥 Скачивание
Скачивайте установщик **только** с [официальной страницы](https://aura-assistant.ru/download):
| Файл | Назначение |
| --- | --- |
| `AURA-Assistant-Setup-x64.exe` | Актуальный установщик (псевдоним последней версии) |
| `AURA-Assistant-Setup-0.4.4-x64.exe` | Версионный файл релиза 0.4.4 |

*На сайте есть карточки Windows 10 и Windows 11 — это одна и та же сборка x64.*

## 🛡️ Почему Windows предупреждает о файле?
AURA распространяется без code signing (без платного сертификата издателя). Поэтому:
- Браузер может написать, что файл «может быть опасен».
- SmartScreen Windows показывает «Система Windows защитила ваш компьютер».
- Иногда срабатывает Защитник Windows с пометкой о неизвестном издателе.

**Это не означает, что файл повреждён.** Так бывает у многих независимых приложений. Главное — скачивать установщик только с [aura-assistant.ru](https://aura-assistant.ru/download), а не со сторонних зеркал.

## ⚙️ Установка по шагам

**1. Сохраните файл и проверьте источник**  
Убедитесь, что адрес сайта именно `aura-assistant.ru`. Не открывайте установщик из писем и чатов неизвестных отправителей.

**2. Если браузер блокирует скачивание**  
В Chrome / Edge: в списке загрузок нажмите `⋯` → **Оставить** (Keep). При необходимости подтвердите «Всё равно скачать».

**3. SmartScreen при запуске установщика**  
Дважды кликните `AURA-Assistant-Setup-x64.exe`.  
Если появится синее окно SmartScreen:
1. Нажмите **Подробнее** (More info).
2. Затем нажмите **Всё равно запустить** (Run anyway).  
*(Если Windows спрашивает разрешение администратора — подтвердите запуск).*

**4. Мастер установки**  
Выберите папку установки (или оставьте предложенную). При желании включите ярлык на рабочем столе. Нажмите **Установить** и дождитесь завершения.

**5. Первый запуск**  
- Разрешите AURA доступ к микрофону, если Windows спросит.
- Пройдите короткий Setup Wizard: проверка микрофона и записи.
- Войдите через Telegram или VK ID.
- При необходимости выберите язык интерфейса.

**6. Проверьте голос**  
На дашборде нажмите кнопку микрофона и скажите коротко: *«Привет»*.  
Нажмите кнопку ещё раз, чтобы завершить разговор. Если включено автоопределение тишины, запись может остановиться сама.

Дальше настройте микрофон, wake word и озвучку: [SETTINGS.md](./SETTINGS.md).

## 🔧 Если Защитник Windows удаляет или блокирует файл
1. Откройте **Безопасность Windows** → **Защита от вирусов и угроз** → **Журнал защиты**.
2. Найдите действие по файлу AURA и выберите **Восстановить** / разрешить.
3. Повторно скачайте установщик с официального сайта и добавьте папку загрузок в исключения, только если вы уверены в источнике файла.
> 🛑 Не отключайте антивирус целиком «на всякий случай».

## 🎤 Настройка микрофона в Windows
1. **Параметры** → **Конфиденциальность и защита** → **Микрофон** — разрешите доступ приложениям (и desktop-приложениям).
2. **Параметры** → **Система** → **Звук** → **Ввод** — выберите нужное устройство.
3. В AURA: **Настройки** → **Голос и микрофон**.

## 🔄 Обновление
AURA проверяет обновления при запуске. При новой версии появится уведомление «Доступно обновление».  
Можно скачать и установить его прямо из приложения. Либо вручную скачайте новый `AURA-Assistant-Setup-x64.exe` с сайта и установите поверх.

## 🗑️ Удаление
**Параметры** → **Приложения** → **Установленные приложения** → **AURA Assistant** → **Удалить**.  
*Пользовательские данные:* `%APPDATA%\aura-assistant-desktop\`  
Удалите эту папку вручную, только если нужна полная очистка (настройки, локальные ключи, история).
